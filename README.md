# Rán's Wake — Windows builds

Download the latest `RansWake-Windows-*.zip` from [Releases](../../releases/latest), extract it somewhere you own (Documents or Desktop, not Program Files), and run `RansWake/RansWake.exe`.

Installed builds update themselves: when a newer build is published here, pause the game and choose **Update**. Each release is tagged `b<build>-<commit>`; the game only moves to a higher build number and verifies the zip's SHA-256 against this repo's asset digest before installing.

Source code is private; this repository holds release assets only.
