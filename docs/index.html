// CONTRACT

How a run goes

01

Wake the relic

Every hold hides a Chain-Scale. Touch it and the guild's clock starts: waves spawn, the pumps fail, and the water begins to climb.

02

Fight in the flood

The water is not scenery. It slows you, drags loose scrap toward the drain, and rises with every wave you clear. Hold the high ground or keep moving.

03

Salvage and refit

Break crates and enemies for scrap, then spend it at the terminal: harder pulse shots, a bigger runic blast, faster legs, a tougher suit. Upgrades carry to the next hold.

ExtractReach the pad before the four-minute window closes. Then go deeper.
Two weaponsPulse Blaster for pressure, Runic Charge for walls, crates and crowds.
High groundPlatforms are real steps up, reached by ramps. The water is shallower there.
One runFour holds back to back. Die and the contract starts over.

Wake Drones

Tidecasters

Casters find a line of sight, fire volleys that cover your strafe, then relocate before you can answer.

// FIELD KIT

Download and play

Download for Windows

Latest build · Windows 10/11 64-bit · zip

  1. Extract the zip somewhere you own, such as Documents or Desktop. Not Program Files: the game updates itself in place.
  2. Run RansWake/RansWake.exe. The build is not code-signed yet, so Windows SmartScreen may say it protected your PC. Choose More info, then Run anyway.
  3. Stay current. When a newer build is published, the game announces it. Pause and choose Update: it downloads, verifies the file against its published SHA-256, installs, and restarts. A failed install rolls back.
